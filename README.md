# 🏎️ Portfólio — Fórmula 1, Engenharia e Inteligência Artificial

Bem-vindo ao meu portfólio de projetos que exploram a conexão entre **Engenharia Mecânica, automobilismo, carros esportivos e Inteligência Artificial**.
